# DCSZ-Maths-KS3-Mr-Sawyer

Resources and challenges for KS3 maths, served by GitHub Pages at
https://noxioussawyer.github.io/DCSZ-Maths-KS3-Mr-Sawyer/

| Folder | What it is | Who it's for |
|---|---|---|
| `/` | Landing page with links | Students |
| `practice/` | Maths Practice: levelled practice in number facts, number skills, fractions/decimals/percentages and word problems | Students |
| `practice/packs.js` | Extra word problems (optional; the app works without it) | Students |
| `fact-sessions/` | Fact practice sessions for 1–3 students who need fact families: session screen, printable sheets, fact maps, parent reports | Teacher |

All progress is saved in each person's own browser. Nothing about students is stored in this repo.

**Keep these addresses the same.** Progress is tied to the web address, so moving the site to another GitHub account or host would start everyone fresh. Changing what's inside the files is fine.

Design notes and plans are kept in the Claude project "Student Retrieval Tracker": `maths-practice-principles.md` and `maths-practice-number-map.md`.
